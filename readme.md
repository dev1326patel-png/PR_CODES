# PR2 - Logic Box: Pattern Generator and Number Analyzer

## 📌 Project Description
This Python program, **Logic Box**, demonstrates fundamental Python programming concepts such as control statements, loops, nested loops, range(), and input validation.

It provides two main functionalities:
1. Generate a right-angled triangle pattern using nested loops.
2. Analyze a range of numbers by identifying odd/even numbers and calculating their sum.

The program also demonstrates the use of `break`, `continue`, and `pass` statements through a menu-driven interface.

## 🎯 Objectives
- Understand and implement Python control structures.
- Practice `for` and `while` loops.
- Generate patterns using nested loops.
- Use the `range()` function to iterate over numbers.
- Understand `break`, `continue`, and `pass` statements.
- Implement input validation and exception handling.
- Develop a menu-driven Python application.

## ⚙️ Features

### 1. Pattern Generator
- Accepts the number of rows from the user.
- Generates a right-angled triangle using `*`.
- Uses nested `for` loops.
- Validates that the row count is positive.

**Example Output:**
```text
Enter the number of rows for the pattern: 5

*
**
***
****
*****
```

### 2. Number Analyzer
- Accepts a starting and ending number.
- Identifies whether each number is odd or even.
- Calculates the sum of all numbers in the given range.
- Demonstrates the `continue` statement by skipping further processing for 13.
- Validates the range entered by the user.

**Example Output:**
```text
Enter the start of the range: 1
Enter the end of the range: 5

Number 1 is Odd
Number 2 is Even
Number 3 is Odd
Number 4 is Even
Number 5 is Odd

Sum of all numbers from 1 to 5 is: 15
```

### 3. Menu-Driven Interface
The program provides three options:
- Option 1: Generate a Pattern
- Option 2: Analyze a Range of Numbers
- Option 3: Exit the Program
